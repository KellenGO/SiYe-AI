# 四野 AI 研究助手

四野的可选官方扩展。用户在「设置 → 扩展管理」下载、开启或卸载。基础四野不包含模型 SDK 或 Claude 运行程序。

运行程序只接收当前任务的资料、模型配置和最近问答，不读取四野数据库、平台登录资料或笔记编辑器。JSON 行协议版本为 1；资料抓取、任务取消、历史持久化、密钥加密和笔记写入由四野提供。界面使用四野提供的 React 实例、查询和翻译环境及笔记桥接接口。

## 安装和使用

需要支持扩展管理的四野主程序（版本 1.2.0 及以上，2.0.0 之前），目前支持 Windows x64。在四野中进入「设置 → 扩展管理」，下载 AI 研究助手并开启，然后配置自己的模型服务。首次安装默认关闭。

正式安装包见 [GitHub Releases](https://github.com/KellenGO/SiYe-AI/releases/latest)，用户通过四野的扩展管理安装。关闭扩展结束正在运行的 AI 任务；卸载默认保留配置和聊天记录，空间资料及笔记保留。

## 开发和验证

Python 3.11+，按 pyproject.toml 安装依赖；webui 内运行 npm ci。Python 测试用 python -m pytest tests；界面用 npm run build。模型测试只用模拟服务，不调用真实付费模型。

界面可以在不启动主程序的情况下预览：webui 内 npm run preview:panel 起本地预览台（mock 数据，默认 5288），端口不可用时用 npm run preview:static 构建静态页面直接打开；npm run shot 用无头浏览器截图。面板样式跟随主程序主题变量，流式渲染的宿主契约见 [docs/streaming-and-ui.md](docs/streaming-and-ui.md)。

## Windows 发布

运行 python scripts/build.py，输出 dist/SiYe-AI-Windows-x64.zip 及 SHA256 文件。用户无需安装 Python 或 Node。包内 extension.json 声明插件版本及四野版本范围。GitHub Release 标签必须与扩展版本一致，正式下载来源固定为 KellenGO/SiYe-AI。

首次安装默认关闭；开启后在空间显示 AI 入口。停用结束正在进行的任务，保留配置和历史；卸载可以单独选择清除 AI 数据。可选视频转写由四野的资料获取能力提供，仍按需安装。

## 默认阅读范围

新版主程序可在本地识别小红书图文配图文字，插件将其作为独立 `ocr` 分区，与正文和评论一起必读。按原图序号读取，用 `[S1:ocr]` 引用，支持普通回答、结构化结果、流式角标和上下文复用。资料详情区分已处理图片、识别失败及 AI 读取，失败可另开一轮重试，保留原答案。旧会话可补取此前没有的图片文字。

OCR 仅提取文字，不理解画面；由 Windows 内置中文 OCR 和主程序已有图片解码能力提供，不需要图片模型或新 Key。缺少中文 OCR 组件、图片不可取、无文字、超限或失败会明确显示；错字、数字与排版需对照原图。必须同时更新主程序和插件，旧主程序不采集图片文字。

四个平台统一按类型阅读：视频读完可用字幕和评论，图文笔记、文章、回答读完可用正文和评论。视频简介不强制与字幕重复读取；没有字幕时可读简介补充，但不能据此声称已知视频讲话。其它部分及已打开的网页正文一旦开始读取，也要读完当前可读分段；平台未取得的内容保留缺口。

普通回答和结构化提交共用完成检查。模型提前结束时返回具体待读分段，补读后再接受答案；连续三次尝试结束而没有新的阅读时停止，不把部分阅读当作完成。流式草稿被退回补读时会清空，已读记录与上下文整理保持连续。

同一会话在上次成功回答后的 30 分钟内可按当前模型预算复用原文。宿主保存分段指纹，插件校验来源和原文一致后将文字重新放入请求，详情显示「上下文复用」。过期、变化、超预算或旧历史缺少记录时重新补读，旧回答不是证据。缓存需要新版主程序桥接；旧主程序仍可正常使用逐轮读取。此功能减少工具往返，不保证模型服务免收输入 token 费用。

回答底部只保留复制、分享、重做三个图标，悬停可查看名称；复制保留来源链接，重做保留原回答并追加另一版本。回答内选中文字可引用提问，先带入输入框，用户自行补充发送。重做需要新版主程序接口。读取记录只能证明文本已交给模型，不能保证理解或结论准确。

分享默认选中当前问答，可勾选多轮或全选，预览时可切换是否包含问题。保存的 PNG 长图使用白底，保留正文排版、引用及来源标题和链接，隐藏工具过程和操作按钮。图片在浏览器本地生成，不请求模型、不上传、不自动发送；下载后自行转发。内容超过画布保护上限时请减少问答重试。此功能使用浏览器原生绘图，无新增依赖；需要同步更新主程序分享文案。构建两份前端后，可在主仓库运行 `scripts/research_ui_smoke.py --share-only`，实际检查 PNG、选择、超限、Esc 和窄屏。

## 依赖维护

当前界面沿用主项目的 Axios 1.13.2 和 Vite 6.4.1。2026-10-10 的 npm audit 报告两项 high，Vite 是开发／构建依赖，Axios 用于浏览器界面。针对现有使用方式的影响评估和依赖升级仍待独立维护；已发布包的功能测试通过不代表依赖审计通过。
